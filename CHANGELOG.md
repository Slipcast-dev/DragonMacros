# История изменений

## 0.3

- Кнопки «Загрузить» и «Сохранить» конфига макросов (JSON, место выбирает пользователь; ⌘O / ⌘S, меню «Файл»). Загрузка заменяет текущие макросы или добавляет к ним; файл проверяется, размер ограничен, макросам выдаются новые идентификаторы.
- Оформление в стиле macOS: кнопки шапки с символами SF Symbols и подсветкой при наведении, исправлена кнопка «Настройки».
- Чёткая крупная эмблема дракона в шапке, новый слоган «Доли секунды решают всё. Макрос решает за них».
- Значок в строке меню: дракон в круге вместо буквы «M».
- Более тёмная и спокойная палитра всех стилей.
- Сборка: версия 0.3, новая цель `pkg` (установочный пакет), контрольные суммы `dist/SHA256SUMS.txt` для всех установщиков.

## 0.2

- Глобальные горячие клавиши для приложений и ссылок.
- Интерфейс RU / EN, три варианта оформления, настройки Dock и строки меню.
- Пауза макросов и автозапуск через LaunchAgent.
- Блокировка ряда опасных URL-схем, приватные права сохраняемого файла.

## Подготовка публичного репозитория

- CI со сборкой universal и проверкой подписи, Dependabot для GitHub Actions.
- Документация участия, правила сообщества, шаблоны issues и PR, CODEOWNERS.
- Новый комплект графики и уточнение ограничений безопасности.
