# Правила сообщества / Code of conduct

Уважайте участников, обсуждайте решения по существу, допускайте разные уровни опыта.
Приветствуются конструктивная критика, воспроизводимые отчёты и помощь новичкам.
Недопустимы оскорбления, дискриминация, угрозы, преследование, спам и публикация
чужих личных данных. Правила действуют в issues, pull requests и обсуждениях проекта.

Владелец @Slipcast-dev рассматривает нарушения и может удалить материалы,
закрыть обсуждение или ограничить участие соразмерно нарушению.
Для непубличного обращения используйте контакт, добровольно опубликованный
в [профиле владельца](https://github.com/Slipcast-dev).
Не публикуйте личные данные и детали уязвимостей в публичном обращении.
