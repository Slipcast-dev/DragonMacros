# Состояние проекта

Дата: 2026-11-26. Версия: 3.1, build 8.

## Архитектура

Нативное приложение macOS 11+ на AppKit и Carbon. Сторонних Swift-зависимостей нет.
Сборка выполняется `swiftc` без Xcode; универсальный бинарник объединяет arm64 и x86_64.

| Файл | Ответственность |
|---|---|
| `Models.swift` | Модель макроса и сочетания, проверка допустимых клавиш |
| `MacroStore.swift` | Транзакционное хранилище, импорт и экспорт JSON, резервные копии |
| `Hotkeys.swift` | Регистрация глобальных сочетаний Carbon, повтор отказов, конфликты |
| `Actions.swift` | Запуск приложений и политика открытия ссылок |
| `Settings.swift` | Настройки, язык, автозапуск (SMAppService / LaunchAgent) |
| `Updater.swift` | Проверка релизов GitHub, загрузка и проверка установщика |
| `MainWindowController.swift`, `SettingsWindowController.swift` | Окна |
| `Controls.swift`, `SamuraiBackdrop.swift`, `Theme.swift` | Элементы интерфейса, фон, палитры |

## Модель безопасности

- **Ссылки.** Сразу открываются `http`, `https` и `mailto`. `file`, `javascript`,
  `data` и `vbscript` запрещены. Остальные схемы требуют подтверждения; «Всегда открывать»
  запоминает пару схема+узел (не для `ssh` и системных настроек), сброс — в настройках.
- **Импорт.** До 2 МБ и 500 макросов, проверка `app`/`version` и сочетаний, новые UUID.
  Перед применением пользователь видит список приложений, ссылок и сочетаний.
- **Хранилище.** Временный файл с правами 0600 атомарно заменяет `macros.json`,
  каталог данных — 0700. Повреждённый файл копируется (больше 2 МБ — переносится)
  в `macros.corrupt-<UUID>.json`; если резервирование невозможно, запись блокируется.
- **Сочетания.** Пока идёт запись нового сочетания, глобальные регистрации сняты;
  запись прерывается при потере фокуса, закрытии окна и переходе в другое приложение.
- **Обновления.** Единственный сетевой запрос — `releases/latest` API GitHub (при запуске
  и раз в сутки, выключается). Загружаются только файлы релизов этого репозитория по HTTPS;
  `.pkg` сверяется с `SHA256SUMS.txt` того же релиза, проверяются размер (до 100 МБ) и
  сигнатура xar, затем установку выполняет «Установщик» macOS. Контрольная сумма из того же
  релиза не защищает от компрометации репозитория: для этого нужна подпись Developer ID.
- **Один экземпляр.** Второй запуск передаёт работающей копии команду показать окно
  и завершается, поэтому сочетания не регистрируются дважды.

## Производительность

Меню установленных приложений и их иконки строятся один раз, строки списка
переиспользуются, иконки шапки кэшируются. Фоновая анимация Samurai работает только
в активном, видимом и не закрытом другими окнами окне. Все сборки — с `-O`.

## Запуск и проверка

```sh
./test.sh
python3 -m unittest discover -s Icon -p 'test_*.py'
./test-interface.sh
./build.sh universal test-app dmg pkg
```

Нужны macOS, Apple Command Line Tools и Python 3. Кэши и результаты — в `.build`,
установщики и `SHA256SUMS.txt` — в `dist`. Для подписи Developer ID и нотаризации
задайте `SIGN_IDENTITY`, `PKG_SIGN_IDENTITY` и `NOTARY_PROFILE`.

## Сохраняющиеся границы

Приложение не использует App Sandbox. Подтверждённая ссылка передаётся системному
обработчику, а расширение `.app` не подтверждает доверие к пакету: импортируйте
доверенные конфиги. Права файлов не являются шифрованием и не защищают от процессов
того же пользователя.

Публичные сборки подписаны ad-hoc и не нотаризованы: для Developer ID нужны сертификат
владельца и учётная запись Apple. Автотесты не заменяют ручную проверку глобальных
сочетаний, окна подтверждения ссылок, установки обновления через «Установщик», автозапуска через объекты входа и воспроизведения
анимации в реальном окне. История проверок прошлых версий — в истории git.
