# Анализ проекта

Дата: 2026-10-30 (версия 0.3). Объём: исходники, сборочный скрипт, графика, документация,
локальная история Git. Это инженерный обзор, не полный аудит безопасности.

## Архитектура

Приложение на AppKit и Carbon, без сторонних Swift-зависимостей.
`Sources/main.swift` объединяет модель Codable, JSON-хранилище, регистрацию
горячих клавиш, запуск действий и интерфейс. Для текущего небольшого объёма
переход на новый стек или фреймворк не требуется.
Сборка выполняется `swiftc`, универсальный бинарный файл объединяется `lipo`.

## Существенные ограничения

1. `MacroStore.save()` и LaunchAgent используют `try?`: пользователь может
   не узнать о неудачном сохранении. Следующее улучшение — возвращать ошибку
   и показывать её в интерфейсе, уведомлять `onChange` только после успеха.
2. Проверка `.app` подтверждает расширение и наличие каталога, но не доверие
   к приложению и не его подпись. Запускайте только выбранные доверенные приложения.
3. URL использует blocklist из четырёх схем. Прочие системные обработчики
   могут запускать приложения и инициировать действия. Это не песочница ссылок.
4. Обработка повреждённого JSON подавляет ошибки копирования резервной копии;
   существующая копия может замениться. Нужны уникальные имена и обработка ошибок.
5. Права 0700 задаются при создании каталога, 0600 — после записи файла.
   Это не шифрование и не защита от других процессов того же пользователя.
6. Регистрация Carbon и чтение параметров события не везде проверяют OSStatus.
7. Ad-hoc подпись и hardened runtime не заменяют Developer ID и нотариализацию.
8. Автотестов поведения пока нет. CI подтверждает сборку и структуру пакета,
   но не работоспособность сочетаний и интерфейса на всех версиях macOS.

## Обновление 0.3

Добавлены загрузка и сохранение конфига. Файл ограничен 2 МБ и 500 макросами,
идентификаторы заменяются при чтении; запуск действий по-прежнему проходит
через проверки `runMacro` (только `.app`, блокировка `file:`/`javascript:`/`data:`).
Загруженный конфиг может ссылаться на любые приложения и ссылки — загружайте
только файлы из доверенных источников. Ошибки записи конфига показываются
пользователю. Остальные ограничения выше сохраняются.

## Публикация

Графика проекта собственная (см. [NOTICE.md](../NOTICE.md)); сторонних изображений
и старых дистрибутивов в репозитории нет. Установщики (`.dmg`, `.pkg`) публикуются
как файлы GitHub Release вместе с `SHA256SUMS.txt`, а не коммитятся в репозиторий.

Локальный pre-commit и `.gitignore` — вспомогательные меры. Защита `main`,
secret scanning, push protection и приватные отчёты требуют настроек на GitHub.
