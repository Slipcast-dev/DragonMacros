# Участие в проекте / Contributing

Обсуждение и pull requests принимаются на русском и английском языках.
Перед крупными изменениями опишите задачу в issue. Для исправлений создайте ветку от `main`.

## Локальная проверка

Требуются macOS и Apple Command Line Tools (`xcode-select --install`).

```sh
git config core.hooksPath .githooks
sh -n build.sh .githooks/pre-commit
python3 -m py_compile Icon/*.py
./build.sh universal
codesign --verify --deep --strict .build/DragonMacros.app
```

Pillow нужен только для подготовки графики: `python3 -m pip install Pillow`.
Для обычной сборки достаточно Python 3 и системных утилит macOS.

Проверяйте открытие приложения и ссылки, конфликты сочетаний, паузу,
перезапуск, темы и оба языка. Описывайте фактические проверки в PR.
Не добавляйте личный `macros.json`, секреты, сертификаты, `.build/` и `dist/`.
Не переформатируйте несвязанный код. Комментарии и docstring пишите на русском,
идентификаторы — на английском. Сохраняйте совместимость с macOS 11.

Код и документация публикуются под MIT. Добавляя материалы, убедитесь,
что имеете право распространять их на условиях проекта; указывайте происхождение графики.
Об уязвимостях сообщайте приватно по [SECURITY.md](SECURITY.md).
