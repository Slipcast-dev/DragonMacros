# Политика безопасности / Security policy

## Что делает приложение
- Регистрирует глобальные комбинации клавиш (Carbon `RegisterEventHotKey`) и по ним **открывает приложения (`.app`) и ссылки**. Ввод с клавиатуры не читается и не записывается, разрешения «Мониторинг ввода» и «Универсальный доступ» не нужны.
- Сети не использует, ничего не отправляет. Ссылки открываются системой в браузере по умолчанию.
- Схемы `file:`, `javascript:`, `data:`, `vbscript:` в ссылках блокируются; запускаются только пакеты `.app`.
- Конфиг для переноса (кнопки «Сохранить» / «Загрузить») — обычный JSON в папке, которую выбирает пользователь. Загружайте только файлы из доверенных источников: конфиг может ссылаться на любые приложения и ссылки. Размер файла ограничен 2 МБ, число макросов — 500.
- Данные: `~/Library/Application Support/DragonMacros/macros.json` (права 0600, папка 0700), настройки — `UserDefaults`, автозапуск — `~/Library/LaunchAgents/dev.slipcast.dragonmacros.plist` (только по включённому пункту «Запускать при входе в систему»).
- Сборка подписана ad-hoc с hardened runtime, **не нотаризована**. Проверяйте контрольные суммы `.dmg` и `.pkg` по `SHA256SUMS.txt` из страницы релиза или собирайте из исходников.

## Как сообщить об уязвимости
Не публикуйте детали в открытом виде. Используйте [приватное сообщение об уязвимости](https://github.com/Slipcast-dev/DragonMacros/security/advisories/new),
если GitHub показывает эту возможность. Если она недоступна, используйте контакт,
добровольно опубликованный в [профиле владельца](https://github.com/Slipcast-dev).
Укажите версию, macOS, шаги воспроизведения и влияние. Срок ответа не гарантируется.

## Поддерживаемые версии

Исправления выпускаются для текущей версии 0.3; старые версии отдельно не поддерживаются.

## Границы защиты

Приложение не использует App Sandbox. Blocklist URL-схем не гарантирует безопасность
остальных системных обработчиков. Расширение `.app` не подтверждает доверие к пакету.
Права файла не являются шифрованием. Некоторые ошибки записи пока подавляются;
детали — [PROJECT_REVIEW.md](docs/PROJECT_REVIEW.md).

## Чего в репозитории быть не должно
Паролей, токенов, ключей подписи и сертификатов (`.p12`, `.pem`, `.mobileprovision`), персональных данных. Защита: `.gitignore` и хук `.githooks/pre-commit`, который блокирует такие файлы и подозрительные строки перед коммитом.
Включить хук после клонирования: `git config core.hooksPath .githooks`.
